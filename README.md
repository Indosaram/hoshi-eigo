# 호시약대 B방식 영어 독학 · 星薬科大学 一般選抜B方式 英語

星薬科大学 薬学部 **薬学科(6년제)** 一般選抜 **B方式** 영어 시험을, 영문법을 전혀 모르는 사람도 혼자 공부할 수 있도록 만든 한국어 학습 사이트입니다. 설명은 한국어, 문제·지문은 실제 시험처럼 영어/일본어 그대로입니다.

**👉 사이트: https://indosaram.github.io/hoshi-eigo/**

## 들어 있는 것
- **시험 분석**: 70분·100점·마크시트·대문 I~IX 구성, 대문별 경향, 공식 경쟁률(2024~2026), 시간 배분
- **학습 로드맵**: 문법 0 → 합격권 6개월 계획
- **왕기초 문법 27강**: 품사·문장 성분·5형식부터 관계사·분사·가정법·비교, 정렬/오류찾기/장문 전략까지. 강의마다 星薬 형식 확인 퀴즈 6문항
- **기출 3개년**: 대학이 공식 공개한 2024·2025·2026년도 B방식 영어 전 문항(각 40문항) 전사 + 문항별 한국어 해석·정답 근거·오답 분석, 지문 번역, 70분 타이머, 원본 PDF 링크
- **어휘·숙어**: 기출 어휘·필수동사·숙어·의약 용어 280여 개, 플래시카드
- **의약 장문 8편**: 星薬 스타일 자체 제작 지문, 문장별 끊어 읽기·직역·문법 구조 해설 + 문제
- **자료 모음**: 공식 기출·입시 정보·분석 글·무료 문법/어휘/독해 자료 링크

학습 기록은 브라우저 localStorage에만 저장됩니다.

## 주의
- 비공식 사이트이며 星薬科大学과 무관합니다. 기출문제 저작권은 星薬科大学에 있습니다 ([공식 과거문제 페이지](https://www.hoshi.ac.jp/admission/nyushi/exam/)).
- 대학은 정답을 공개하지 않습니다. 정답·해설은 본 사이트의 자체 풀이이며 오류가 있을 수 있습니다. 발견하면 Issue로 알려 주세요.
- 입시 요강은 매년 바뀔 수 있으니 [공식 입시 페이지](https://www.hoshi.ac.jp/admission/nyushi/)에서 확인하세요.

## 개발
```bash
bun install
bun run dev      # 로컬 개발
bun run build    # tsc -b && vite build → dist/
```
React 19 + Vite + TypeScript + Tailwind CSS 4. 콘텐츠는 `src/data/` (문법: `grammar/lessons/*.ts`, 기출: `papers/*.ts` + `papers/explanations/*.json`, 장문: `readings/*.ts`, 어휘: `vocab.ts`). GitHub Actions로 Pages에 자동 배포.
